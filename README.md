# ARVIO Live (personal build)

Install files for a personal build of [ARVIO](https://github.com/ProdigyV21/ARVIO), an open-source media app
licensed under the Apache License 2.0. This build changes the Live TV experience for one household's Google TV.
It is not an official ARVIO release and is not supported by the ARVIO developers.

This repository holds release files only: no source code, no accounts, no passwords.
Latest app file: `releases/latest/download/ARVIO-Live.apk`
